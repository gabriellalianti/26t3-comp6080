## Replicate static html/css of a simple section of an Airbnb webpage

`airbnb.png` is a "Contact Us" page taken from the airbnb website.

Create a page in `airbnb.html` that uses HTML and CSS to produce a page that looks as close to the png as possible.

Hint: The font-family is `Circular`, which you don't have to replicate. Focus on structure, spacing, and font-sizes.

## Interactive behaviour

In addition to the static layout, implement the following mouse interaction effects using CSS:

- **Buttons (`Log In` / `Sign Up`):** The cursor should change to a pointer when hovering over either button. Both buttons should become slightly transparent (`opacity: 0.85`) on hover to indicate they are clickable.
- **Article list items:** Each list item should display a pointer cursor on hover. When hovered, the item should gain an underline to indicate it is a link.
